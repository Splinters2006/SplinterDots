# SplinterDots Center Fixes

Run from the root of the SplinterDots repo:

```bash
./apply_center_fixes.sh
```

This patches:
- theme saving
- wallpaper applying
- broken messagebox crash after save
- overview shortcut cards updating when shortcuts change
- selected tab being taller
- Hyprland page hiding open-ended expert fields
- QML bar using the real active workspace instead of always workspace 1
